# Supratik Bhattacharya

Academic website: https://supratik-bhattacharya-2020.github.io/supratik_portfolio/

- `index.html`: research, publications, experience, education, and contact details.
- `assets/css/site.css`: responsive layout and visual styling.
- `assets/pdf/Supratik_Bhattacharya_CV.pdf`: downloadable CV.

The homepage uses plain HTML and CSS, with no JavaScript or external font dependencies.
GitHub Pages publishes the root of `main`. Relative asset paths support the project's
`/supratik_portfolio/` URL.

For a local preview, run `python -m http.server 8000` in the repository and open
`http://localhost:8000`.
